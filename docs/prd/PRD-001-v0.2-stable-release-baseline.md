# PRD-001 v0.2 稳定发布基线

## 背景

应用功能已覆盖浏览 / 单图编辑 / 批量编辑 / 设置四个视图（当前 `package.json`、`src-tauri/Cargo.toml`、`src-tauri/tauri.conf.json` 版本均为 0.1.0），但发布前缺少工程化收口：环境依赖未锁定、前端质量门禁未清零、Rust 测试存在触碰真实目录的风险、批量处理输出目录等于输入目录时可能无提示覆盖原图、无 CI、文档工具校验未纳入收口流程。

## 目标

v0.2.0 稳定发布基线，达到以下工程化门槛：

- 环境依赖锁定（Node / pnpm / Rust 工具链），构建可复现
- 前端质量门禁清零：lint 零错误、类型检查通过、测试全绿、doctor 无债务
- 版本号统一为 0.2.0（package.json / Cargo.toml / tauri.conf.json / About 视图）
- Rust 测试安全：测试不触碰用户真实目录，全部隔离在临时目录
- 批量处理输出目录等于输入目录：允许，但前端必须明确不可恢复风险并二次确认（见 [ADR-0004](../adr/0004-batch-output-same-dir.md)）
- 新增 CI 工作流，push/PR 自动跑全部质量门禁
- 文档工具（`project_docs.py` validate / index check）纳入收口

## 范围

- 仅工程化与质量收口，不新增业务功能
- 唯一交互变更：批量处理同目录覆盖确认（ADR-0004）
- 本期不做 Linux / macOS CI 发布，只保证测试命令跨平台可跑

## 验收标准

- [x] `pnpm lint` 零错误，`pnpm test` 全绿，`pnpm build` 成功，`pnpm doctor` 无债务
- [x] `cd src-tauri && cargo test` 全绿，测试不写入用户真实目录
- [x] 三处版本号（package.json / Cargo.toml / tauri.conf.json）均为 0.2.0
- [x] 批量处理输出目录 == 输入目录时，前端弹明确警告 + 二次确认，取消则不执行
- [x] CI 工作流全绿，使用锁定版本与 frozen lockfile
- [x] `python tools/project_docs.py validate` 零断裂链接
- [x] 实施计划 [PLAN-003](../plan/PLAN-003-stable-release-baseline.md) 及全部工单关闭
