# BUG-004 假扩展名图片加载失败

## 背景

用户反馈：把 PNG 拖到单图编辑预览区报错 `加载失败:读取图片尺寸失败:Format error decoding Png: Invalid PNG signature.`

取证（已本地复现）：

- 报错文件 `小程序码-员工工作台.png` 实际是 JPEG（文件头 `ffd8 ffe0 ... JFIF`），扩展名是 `.png` 的"假 PNG"。微信小程序码导出常见此情况。
- `get_image_info`（src-tauri/src/image_ops.rs:97）用 `image::image_dimensions(path)`，该函数按扩展名选解码器 → 按 PNG 解码 JPEG → Invalid PNG signature。
- 用 `image::ImageReader::open(p).with_guessed_format()` 内容嗅探验证：假 PNG 正确识别为 Jpeg，尺寸 430×430 可读。

## 目标

- 图片按文件内容（魔数）识别格式，不信任扩展名。
- 修复范围先覆盖 `get_image_info`（加载链路入口）；其余按扩展名解码的命令在受影响时再跟进。

## 验收标准

- [x] 假 PNG（实为 JPEG）能正常加载并显示正确尺寸。
- [x] 真 PNG / JPG / WebP / BMP 不回归。
- [x] Rust 单测覆盖"扩展名与内容不一致"用例。
