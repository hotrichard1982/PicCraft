# BUG-003 单图编辑保持原图比例换算错误

## 背景

用户反馈：单图编辑中勾选"保持原图比例"后，修改宽或高，另一侧数值不按正常比例换算。

复现路径（例）：

1. 打开 4000×3000 原图，裁剪成 1000×500（temp 图）。
2. 勾选"保持原图比例"，宽度输入 500。
3. 期望高度 250（按当前编辑图 2:1），实际得到 375（按原图 4:3 换算）。

根因（代码取证）：

- `src/components/SingleTab.tsx` 的 `handleWidthChange` / `handleHeightChange` / `handleAspectToggle` 换算时使用 `img.imageInfo`（原图尺寸）。
- 裁剪/缩放/旋转后编辑图尺寸已变化，`setTempPath` 只更新 displayPath/tempPath，不更新 imageInfo。
- `apply_transforms` 旋转 90° 后宽高互换，用原图比例换算同样错误。
- 另外 `handleResize` 在 keepAspect 时用 `Math.min` 比例约束，也是基于 `img.imageInfo` 原图尺寸，语义应为"按当前编辑图保持比例"。

## 目标

- keepAspect 换算基于"当前编辑图"（tempPath 存在时为 temp 图尺寸，否则原图尺寸）。
- 换算函数保持纯函数（single-tab-state.ts），可单测。

## 验收标准

- [x] 纯函数 `currentEditSize(state)` 返回当前编辑图尺寸（temp 优先），有单测。
- [x] 修改宽度时高度按当前编辑图比例换算；修改高度同理。
- [x] 勾选保持比例时立即按当前编辑图比例校正另一侧。
- [x] 应用缩放（keepAspect）的 Math.min 约束同样基于当前编辑图尺寸。
- [x] 既有测试全部通过。
